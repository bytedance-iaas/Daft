# 增广三条路线对比：纯链式 / maskfree（链式改进，默认） / 掩码版（2026-09-07）

同一条 so101 episode（ep0，规格对齐的新源视频 lerobot_curated_v2），同一句抛光金银提示词，同一个 Seedance 2.5。三条路线只在“几何层怎么做”上不同。

## 一、工作原理

| 环节 | 纯链式（`--chain-only`，老 mw_final） | maskfree（默认） | 掩码版（`--geom <档案>`） |
|---|---|---|---|
| 前置处理 | 无 | 无 | 几何档案：VLM 物体清单 → GroundingDINO 出框 → VLM 绿框核验 → SAM2 分块传播 → Depth‑Anything；CPU 约 26 分钟/条，一条数据算一次可复用 |
| 目标解析 | 不解析 | VLM 看首帧列物体清单，再把编辑指令映射到清单里的目标；材质短语由 VLM 从指令抽取 | 同左，但清单来自档案，映射时附带首帧标注图 |
| 切段 | 按段长上限等分（17 秒两段） | 从段长下限起每 2 秒问 VLM“所有目标是否可见且未被夹持”，切在第一次被夹之前最后一个全可见秒；全程可见则切在上限 | 用掩码算“目标可见且静止”的帧，切在这样的时刻（`choose_cuts_v2`） |
| 段间接力 | 上一段生成末帧作 `@图片1` + 链式句 | 同左 | 同左 |
| 身份锚帧 `@图片2` | 无 | 在前段范围内，看**源视频**从段尾每 4 秒探一次“所有目标可见”，命中的时刻取前段**生成**帧当锚帧 | 用掩码在前段找“所有目标可见且静止”的帧 |
| 逐抽·脑补门 | 有（原/生成并排问 VLM 有没有多画） | 有 | 有 |
| 逐抽·并排门（新增/消失） | 有（`--vlm-gate`） | 有 | 有 |
| 逐抽·意图门（材质对不对） | 无 | **原帧｜生成帧同一时刻并排**，物体名指左图，看右图同位置；只判材质/颜色，不判质感；段内均匀 4 个时刻 × 3 票 | 用掩码裁出目标、绿线勾轮廓问 VLM；每次露面区间中点各问一次 × 3 票 |
| 首段多抽择优（`--pick-draws`） | 无 | 原帧作参考 + 候选整帧并排标字母，问哪张材质与质感最贴指令 | 用掩码裁目标区域并排比较 |
| 身份判定依据 | 无（靠模型自觉） | **位置对应**（同一时刻同一位置） | **掩码**（像素归属） |
| 后处理 | 无 | 无（碎片门、合成不可用） | 可选：碎片门 `--sliver-gate`、合成 `--composite`，默认都关 |
| 封数据集 | 按源 info.json 编码规格重编码 | 同 | 同 |

## 二、区别的本质

- 纯链式把身份完全交给模型：接力时只给上一段末帧，若那一帧目标被夹爪挡住，模型只能猜，v1 就在 17 秒切段处金银互换。
- maskfree 和掩码版都补了三件事：不在目标被遮挡时切段、给一张目标全可见的锚帧、每段核一次材质。区别只在“怎么知道目标在哪”：maskfree 让 VLM 看整帧并靠同一时刻的位置对应，掩码版靠 SAM2 逐像素归属。
- 掩码版精度更高（能裁到目标区域），但掩码本身不可靠：夹持期整段丢失、夹爪与底座掩码重复、臂与夹爪逐帧互换；且像素级手术（碎片修补、合成）在两条真实数据上都是净亏损，已默认关。
- maskfree 判定粗一些，但不依赖分割质量，没有档案、没有 torch/SAM2/GroundingDINO，新数据集零前置。质感词（抛光）整帧尺度下 VLM 判不稳，所以意图门只判材质，质感交给择优并排比。

## 三、效果、成本、延时（实测）

| 指标 | 纯链式 | maskfree（默认） | 掩码版 |
|---|---|---|---|
| s2 抛光金银（换被操作物体） | v1：第二段金银互换，盒内是银（失败） | mf2：金银不换、盒内是金、抛光；mf1（旧探针）同 | v6：同左 |
| s1 本子换钢板、桌面换木纹（静态编辑） | mw_final_v2：通过 | 未单独跑（切点会落在上限，与纯链式等价） | s1_metal_wood_v2：通过，与纯链式肉眼一致 |
| 夹缝露红（方块被夹时露出一角仍是红） | 有 | 有 | 有（定案不修） |
| 费用 s2 | 27.1 元（但结果错） | 38.8 元（首段 7 秒 × 3 抽择优 + 第二段） | 62.3 元（首段 9 秒 × 3 抽 + 第二段重抽 1 次） |
| 费用 s1 | 27.1 元 | — | 27.5 元 |
| 端到端耗时 s2 | 约 20 分钟 | 40 分钟 | 53 分钟 + 档案 26 分钟（首次） |
| 运动指标 s2（flow_r / lag） | — | 0.641 / −1 | 0.684 / 0（差异在抽卡噪声内） |
| VLM 调用量 s2（估） | 逐抽并排门约 1 次/秒视频 | 探针约 15 次 + 每抽意图门 24 次 + 择优 3 次 + 并排门 1 次/秒 | 每抽意图门 6 次 + 择优 3 次 + 并排门 1 次/秒 |
| 依赖 | 方舟 Seedance + VLM | 同左 | 再加 torch、SAM2、GroundingDINO、Depth‑Anything 权重 |
| 失效模式 | 遮挡处切段导致身份互换；物体消失只能靠并排门 | VLM 判定为概率性，3 票多数；小物体质感判不准 | 掩码丢失/重复；像素手术副作用 |

## 四、结论

默认走 maskfree；掩码版保留为 `--geom` 开关，用于疑难数据、碎片露红续做（SAM 3 路线）和像素级兜底；`--chain-only` 保留为对照基线。
