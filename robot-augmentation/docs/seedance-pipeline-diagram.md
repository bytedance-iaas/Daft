## 与 Cosmos‑Transfer 图的对应

| Cosmos‑Transfer | 我们 |
|---|---|
| 视频预处理产出控制视频（分割、边缘、深度、模糊），逐像素约束生成 | 读场景只用 VLM 看画面，产出的是决策：改什么、在哪切段、拿哪帧当参考、核什么 |
| 几何由输入保证，一次生成整段 | 几何靠外围保证：切段避开遮挡、参考图接力身份、生成后过门不过就重抽 |
| Transfer 是一个带控制分支的模型 | Transfer 是链式分段加两张参考图（末帧续接、锚帧定身份）加三道门 |
| 合并直接拼 | 合并多一步按源规格重编码，不让编码规格本身成为分布差异 |

掩码版（`--geom`）与本图的差别只在「读场景」一个框：三个问题改由 GroundingDINO + SAM2 的逐帧掩码来算，其余相同。
